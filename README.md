# Game Project

A JavaFX-based game application.

## Features

- Built with Java 23 and JavaFX 23.
- Maven build system.
- Structured for scalability.

## Prerequisites

- JDK 23 or later
- Maven 3.8+

## How to Run

1. Clone the repository.
2. Navigate to the project directory:
   ```bash
   cd game
   ```
3. Run the application using Maven:
   ```bash
   mvn clean javafx:run
   ```
